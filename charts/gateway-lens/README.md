# gateway-lens Helm Chart

![Version: 0.1.0](https://img.shields.io/badge/Version-0.1.0-informational?style=flat-square) ![AppVersion: latest](https://img.shields.io/badge/AppVersion-latest-informational?style=flat-square)

A basic Helm chart for deploying [Gateway Lens](../../README.md) into a
Kubernetes cluster.

> Requires **Gateway API v1.6+** CRDs to be installed in the cluster.

## Installing

```sh
helm install gateway-lens oci://ghcr.io/nginxinc/gateway-lens
```

This installs Gateway Lens into the current namespace, exposed via a
`ClusterIP` Service on port `80`. Port-forward to access the dashboard:

```sh
kubectl port-forward svc/gateway-lens 8080:80
open http://localhost:8080
```

## Uninstalling

```sh
helm uninstall gateway-lens
```

## RBAC for Gateway API extension CRDs

Gateway Lens discovers some CRDs at runtime — `parametersRef`/`extensionRef`
targets and Gateway API policy CRDs — rather than from a fixed list, so the
chart's `ClusterRole` can't grant access to them ahead of time. Use one (or
both) of the following mechanisms to grant read-only (`watch`/`list`/`get`)
access to the CRDs your Gateway API implementation defines:

### Providers

This chart ships curated RBAC rule sets for known Gateway API
implementations under `providers/`. Enable one or more by name:

```yaml
rbac:
  providers:
    - nginx-gateway-fabric
```

Currently available providers:

| Provider              | Covers                                                        |
| ---------------------- | -------------------------------------------------------------- |
| `nginx-gateway-fabric` | [NGINX Gateway Fabric](https://github.com/nginx/nginx-gateway-fabric) `gateway.nginx.org` CRDs |

An unknown provider name fails the Helm render immediately, to catch typos.

### Manually added rules

If your provider isn't curated yet, or has added new CRDs that this chart
doesn't know about yet, add them directly with `rbac.extraRules`. Only
`apiGroups` and `resources` are needed — the same fixed read-only verbs are
always applied:

```yaml
rbac:
  extraRules:
    - apiGroups: ["gateway.example.io"]
      resources: ["someextensionpolicies"]
```
